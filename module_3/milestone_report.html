Overview

This report presents an exploratory analysis of the Coursera SwiftKey dataset used for building a text prediction model. The dataset consists of three files in English: blogs, news, and Twitter. The goal is to understand the basic structure and content of the data before building the prediction algorithm and Shiny app.

6. Plan for the Prediction Algorithm and Shiny App

Algorithm:
The prediction model will use an n-gram language model (unigrams, bigrams, trigrams). The approach is:

  1. Build frequency tables of n-grams from the full cleaned corpus.
  2. Use a backoff strategy (Katz backoff or Stupid Backoff): if a trigram is not found, fall back to bigram, then unigram.
  3. Return the top-3 most likely next words given the user’s input.

Shiny App:
A simple interface where the user types a partial sentence and the app suggests the next word in real time. The model will be pre-computed and stored as an .rds file for fast lookup.

Key considerations:

  • Profanity filtering will be applied during corpus cleaning.
  • Low-frequency n-grams (count < 3) will be pruned to reduce memory footprint.
  • The app must respond in under 100ms, so efficiency in the lookup table is a priority.
